# Ice Cream Sales Analysis - Assessment

## 📌 Project Description
This is a C# Console Application developed as part of an assessment.

The program processes sales data (CSV format) and performs:
- Total sales calculation
- Month-wise sales aggregation
- Most popular item per month (based on quantity)
- Min, Max, and Average order quantity per item
- Highest revenue-generating item per month
- Month-to-month growth analysis
- Data validation and error reporting

---

## 🛠️ Tech Stack
- C#
- .NET Console Application
- Collections (Dictionary, List)
- LINQ
